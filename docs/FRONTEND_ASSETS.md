# Frontend visual assets — licenses

- **Lucide React** (`lucide-react` package)

  - Source: https://lucide.dev

## Fonts
- System stack with preferred families: `Manrope`, `DM Sans`, `Segoe UI`, system-ui
- Loaded only if present in the environment; no paid font CDN required.
- Fallback: system sans-serif (no external license obligation).

## Illustrations / generated art
- No third-party proprietary fintech mockup assets are embedded.
- Visual direction is original CSS (gradients, glass panels, radial glow) inspired by publicly shared design motifs, not copied brand artwork.
- Gold-coin style onboarding is approximated with CSS/typography; no scraped PNG from the reference mock is shipped.

## Charts
- Analytics charts use existing in-app SVG/CSS implementations (no new paid chart library).
